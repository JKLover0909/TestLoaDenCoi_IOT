# TestLoaDenCoi_IOT

Dự án thử nghiệm gửi tín hiệu điều khiển MQTT để phát âm thanh thông qua loa/đèn còi IoT.

## 📌 Tính năng chính
- Kết nối tới MQTT Broker.
- Gửi payload JSON điều khiển thiết bị phát audio qua luồng HTTP/MP3.

## 🛠 Hướng dẫn sử dụng
1. Cài đặt thư viện phụ thuộc:
   ```bash
   pip install paho-mqtt
   ```
2. Chạy file mã nguồn:
   ```bash
   python code.py
   ```
